# Mila - AI Built by Women, for Women

A modern, professional website for AI consulting services designed for women entrepreneurs.

## 🚀 Quick Start

**Local Development:**
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

Visit `http://localhost:5000` in your browser.
